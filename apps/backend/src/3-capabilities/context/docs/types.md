# Context types and persistence

## Public type family

The public surface is exported by [`index.ts`](../index.ts).

### `ContextEntry`

`ContextEntry` is defined by [Knowledge](../../../0-platform/knowledge/types.ts) and re-exported by Context to avoid a second reference atom.

```ts
interface ContextEntry {
  id: string;
  kind: string;
}
```

The runtime does not require non-empty strings outside the endpoint parser and does not validate a leaf against the owning resource capability. Set identity is exactly `${kind}:${id}` and is case-sensitive.

### `ContextStoreScope`

```ts
type ContextStoreScope = "user" | "project";
```

The scope selects one of two physical tables already bound to configured user/project identities. It is not a tenant ID and cannot provide an arbitrary table name.

### `ContextRecord`

```ts
interface ContextRecord {
  readonly id: string;
  readonly displayName: string;
  readonly entries: ContextEntry[];
  readonly revision: number;
  readonly createdAt: string;
  readonly updatedAt: string;
  readonly deletedAt?: string;
}
```

| Field | Representation and behavior |
|---|---|
| `id` | Random UUID for declare/compose; promotion creates a different UUID |
| `displayName` | Caller-provided string, or `~${uuid}` for compose; live uniqueness is per table |
| `entries` | JSON array; declare/update deduplicate by `kind:id` while preserving first occurrence |
| `revision` | Starts at 1 and increments on `update`; current delete does not increment it |
| timestamps | ISO strings generated by the manager |
| `deletedAt` | Nullable SQLite column mapped to optional property |

### Configuration

[`ContextManagerConfig`](../context.ts) has `maxEntriesPerContext` and `maxResolveDepth`. Current defaults are 1,000 and 10 in [`loadBackendConfig.ts`](../../../0-utils/config/loadBackendConfig.ts).

## Error family

| Error | Payload | Raised by | HTTP mapping |
|---|---|---|---|
| `ContextNotFoundError` | `id` | update, delete, promote | 404 `not_found` |
| `ContextConflictError` | `displayName` | declare/promote precheck | 409 `conflict` |
| `StaleContextError` | `id`, `current`, `expected` | update's service-level revision check | 409 `stale_revision` |
| ordinary `Error` | message only | configured limits, SQLite failures, other inputs | 400 `bad_request` |

There are no implemented cycle/depth error classes. Resolution silently omits cycles, missing contexts, and over-depth branches.

## Runtime and store interfaces

[`ContextManager`](../context.ts) is asynchronous at its boundary even though the current store is synchronous. Its full methods are documented in [Runtime](runtime.md).

[`ContextStore`](../store.ts) exposes:

```ts
interface ContextStore {
  get(id: string, scope: ContextStoreScope): ContextRecord | undefined;
  getByName(displayName: string, scope: ContextStoreScope): ContextRecord | undefined;
  list(scope: ContextStoreScope, includeAnonymous: boolean): ContextRecord[];
  insert(record: ContextRecord, scope: ContextStoreScope): void;
  update(record: ContextRecord, scope: ContextStoreScope): void;
  softDelete(id: string, scope: ContextStoreScope, deletedAt: string): void;
}
```

The port has no compare-and-swap return value and no `close` method. Callers must not infer an atomic optimistic lock from the interface.

## SQLite representation

[`SQLiteContextStore`](../sqlite-store.ts) opens `./data/contexts.db` in WAL mode. It derives two trusted 16-hex prefixes:

- `ctx_user_${sha256(userId).slice(0,16)}_contexts`
- `ctx_proj_${sha256(projectId).slice(0,16)}_contexts`

Each table stores `entries_json` plus record metadata. A partial unique index enforces exact, case-sensitive `display_name` uniqueness among rows whose `deleted_at IS NULL`.

| Store method | SQL visibility |
|---|---|
| `get` | Selects by ID without filtering `deleted_at` |
| `getByName` | Selects exact display name and live rows only |
| `list` | Live rows only; optionally filters names matching `~%` |
| `insert` | One `INSERT`; SQL primary key and live-name index apply |
| `update` | Unconditional `UPDATE … WHERE id = ?` |
| `softDelete` | Sets only `deleted_at` by ID |

No wire-specific type exists: endpoint responses serialize `ContextRecord` directly, and request parsing builds simple `{id, kind}` objects.
