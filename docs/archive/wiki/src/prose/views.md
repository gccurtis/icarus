## Keys are paths

A view's key is its path under `app-views/categories/`: `<category>.<name>` is `categories/<category>/<surface>/<name>.svelte`. The content and context surfaces glob those directories and resolve a key to a component at runtime, so there is no registry to keep in step — the tree is the registry ([[check:key-vocabulary-matches-the-tree]]). Two files hold the vocabulary as types the model can name: [[file:app/src/lib/representation/data/behavior/workspace/categories.ts]] (generated by `pnpm category-keys`; categories and content views) and [[file:app/src/lib/representation/data/behavior/workspace/views.ts]] (hand-written; context views and inspector lenses, including keys whose panel is designed and not yet built).

Every table below marks whether a key's file exists. A context key with no file is drawn by the context surface as a placeholder naming the key; a content key with no file would be a broken tab, and there are none.

## Categories

Ten categories. Three are singletons — `project-overview`, `agents`, `templates` — whose tab id is the category itself, so every workspace holds one of each ([[file:app/src/lib/representation/data/behavior/workspace/starting.ts]]). What each opens on — its first content view, its default context, and the order of its rail — is `OPENING` in [[file:app/src/lib/representation/data/behavior/workspace/opening.ts]]; the starting frame is a 180px context panel and a 224px inspector, neither collapsed.

## Content views

Thirteen keys, thirteen files. The plane's component is chosen by the active tab's `content`, keyed on the tab so two documents are two editors.

## Context views

Eighty-six keys, four files. `onRail` means some category's `OPENING.rail` lists the key; the label and icon come from [[file:app/src/lib/surfaces/context/procedures/rail-entries.ts]], which is a `Record<ContextView, …>` so a key with no entry fails to compile.

## Inspector lenses

A hundred and nine keys, two files. The `general.*` keys are lenses meant to be shared by every category; none is built.

## Commands

Four command ids and three default chords, from [[file:app/src/lib/model/client/commands/types.ts]]. `$mod` is ⌘ on macOS and Ctrl elsewhere.
