## Identity

**Shows** — `Name · Header`, `Weight · 600`, `Alignment · Center`

**Needs** — the style's fields in the spreadsheet `StyleSet`.

**Open** — this lens is thinner than the document's equivalent and does not carry
value format, borders or fill, all of which a cell style needs. Either the style
holds them and they belong here, or they are per-cell and Styles is only
typography.

## Usage

Starts collapsed.

**Shows** — "Applied to 7 cells."

**Needs** — a count of cells referencing this style.
