Usage the section that says how much an edit here costs.

## Background

**Shows** — `Kind · Solid`, `Color · Paper`

**Needs** — the theme background.

**Open** — only Solid is offered. Whether an image or gradient background exists
is undecided, and the "Kind" field implies it does.

## Colors

**Shows** — Primary · Secondary · Accent 1 · Accent 2

**Needs** — an ordered, named colour set on the theme.

**Open** — what each colour is *for*. Without a role per colour, an element cannot
say "use the accent" and every use is a literal value that will not follow a
theme change.

## Font

**Shows** — `Family · IBM Plex Sans`

**Needs** — the theme's type family.

## Usage
