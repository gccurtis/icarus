## Identity

**Shows** — `Title · Untitled presentation`

**Needs** — draft state on the launcher.

## Format

Aspect ratio, asked explicitly because there is no modeled project or user
default to fall back to, and because changing it later re-frames every element on
every slide.

**Shows** — `16:9 | 4:3`

**Needs** — the presentation's aspect-ratio field.

## First slide

A thumbnail of what you will land on, so the choice is visible rather than named.

**Shows** — a title-and-body thumbnail, captioned "Title and body"

**Needs** — the default layout for a new presentation, rendered as a preview.

**Open** — whether the first slide's layout is choosable here or fixed. Offering
it makes this a small presentation editor; not offering it means the first thing you do
is change it.

## Create

One button. This tab becomes the presentation.
