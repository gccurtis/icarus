[named style lens](../../inspector/resource/named-style-document.md) is where one is edited.

## Named styles

Each row is a name and its typography in shorthand, which is enough to tell two
apart without opening either.

**Shows**

- Body — IBM Plex Sans 15/26
- Heading 1 — IBM Plex Sans 24/32 · 600
- Heading 2 — IBM Plex Sans 18/28 · 600
- Filing caption — IBM Plex Mono 12/16

**Needs** — the document's `StyleSet`.

**Open** — whether a style can be inherited from the project or is always local to
one document. A filing caption defined per document is copied by hand into every
filing.
