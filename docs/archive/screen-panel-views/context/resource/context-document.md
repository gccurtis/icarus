# Context

| View | What it is for | Sections |
| --- | --- | --- |
| Context | What the prompt blocks in this document can look up | Available to prompt blocks · Resolved preview |

A prompt block generates against a scope. This view is where you see which scopes
this document's blocks use and what those scopes currently contain, without
leaving the document.

Editing a Context happens on the Context tab; this view links there.

## Available to prompt blocks

The saved Contexts in play, with what each resolves to right now.

**Shows** — *Field reports 2024–25* — 96 resources; *Regulatory corpus* — 34 resources

**Needs** — the distinct scopes referenced by prompt blocks in this document, each
with a live resolved count.

**Open** — whether this lists only the scopes actually used by blocks here, or
every saved Context so one can be assigned. The two are different views and the
title has to pick one.

## Resolved preview

A sample of what is inside the selected scope, so a scope that has drifted is
visible before a block runs against it. Starts collapsed.

**Shows** — *storm-log-2026-01.csv*, *feeder-12-relay.pdf*, *Ward 3 undergrounding report* · of 96

**Needs** — a bounded resolve of the set, server-side.
