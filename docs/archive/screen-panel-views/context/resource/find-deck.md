## Results

Each hit with the slide it is on and the kind of content it came from — including
speaker notes, which are not on the canvas at all and would otherwise be
unfindable.

**Shows**

- "…mis-coordinated **relay** pair…" — s.4 · Body text · block b_2c8
- "…the **relay** log confirms…" — s.7 · Speaker notes
- "…**relay** coordination study, 2024…" — s.8 · Appendix table

**Needs** — a search across element text, block content and notes, reporting the
slide index and the source kind per hit.

**Open** — whether search reaches into layout-owned locked content. A hit you
cannot edit from the slide needs to say so.
