# Templates

| View | What it is for | Sections |
| --- | --- | --- |
| Templates | The templates available here, grouped by what they make | Documents · Slide decks · Spreadsheets |

Grouped by target, because the first question about a template is what it
produces. Scope and variable count sit on the row, because those are the two
things that decide whether you can use it.

## Panel furniture

A search across templates, and **Open Templates** at the foot.

**Open** — using a template from this view is blocked, because no body entity can
carry a variable key. Until that exists these rows can only open the template,
not instantiate it.
