## This thread

Title, editable, and the three facts that set the thread's job.

**Shows**

| | |
| --- | --- |
| Title | Why did Feeder 12 fail twice? |
| Job | Answer one question |
| Anchored to | Q-14 · Why did Feeder 12 fail twice? |
| Turns | 3 |

**Needs** — the thread record: title, mode, its anchoring `Question` or
`Hypothesis`, and a turn count.

## Asking

Which agent is answering. Set for the whole thread, not per turn, and the section
says so — along with the reason the Copilot is off on this screen.

**Shows** — Grid Analyst, as an avatar that opens the agent.

**Needs** — the thread's persona reference.

## Looking in

What this thread searches, plus whether the web is available to it.

**Shows** — *Field reports 2024–25* — 96, and a line noting the web is used when a
turn asks for it.

**Needs** — the thread's `ResourceSet` reference with a live count, and a web flag.

## Produced

The thread's output as three counts. This is the point of a thread, so it is a
section rather than a footnote.

**Shows** — `Findings accepted · 1`, `Proposed · 2`, `Sources used · 6`

**Needs** — counts of accepted and proposed findings for the thread, and a
distinct count of sources across its turns.

**Open** — a proposed finding has no state in the model. Proposed, accepted and
dismissed must exist before this count can be real.

## Attribution

Starts collapsed.

**Shows** — `Started by · Ana Reyes`, `Updated · just now`

**Needs** — creator actor and update time.
