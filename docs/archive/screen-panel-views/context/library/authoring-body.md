## Outline

Headings with the page each falls on.

**Shows** — *Filing to the Commission* — p.1; *Outage record* — p.1; *Statutory
basis* — p.2

**Needs** — heading blocks and the computed pagination, exactly as in the document
editor.

**Open** — the outline cannot show where variables are, for the same reason
everything else cannot. A template's structure is exactly the part a variable
interrupts, so the omission is felt here more than anywhere.
