06 · the right flank

The inspector

The inspector shows one lens at a time, chosen by the workspace's inspected key and aimed by its selection. A lens is a thin file that works out what is selected and mounts shared sections; a section takes an id, reads the runtime, and writes one path.

Lenses app-views/categories/slide-deck-editor/inspector/*.svelte Sections app-views/categories/slide-deck-editor/components/*.svelte Signals procedures/selecting.ts
1

How a lens is chosen

Nobody names a lens directly. A view that wants the inspector to show something asks procedures/selecting.ts for a signal — a { key, selection } pair — and calls view.inspect(key, selection). The inspector surface resolves the key to the file under inspector/ (or under app-views/general/<name>/ for a general lens) and mounts it; the lens reads view.selection back to find its subject. That indirection is why the canvas, the Layers panel, the Find panel and the group lens all open the same lens for the same object: they all call elementsSignal.

The surface re-creates the lens whenever the key or the selection's id or range changes, not only when the key does — so a half-written comment on one shape is not carried to the next shape. A change to a multi-selection's or a cell selection's ids alone does not re-create it; those lenses derive from the selection reactively and simply update.

2

The shape of a lens

Every lens opens with the same preamble as a panel (workspace state → deck id → runtime in an effect → body), then resolves its subject from the selection: elementIn(body, id) for an object, slideHolding for its slide and position, blockIn for a text block, rangeOf for a caret. It draws PanelCrumbs — Deck › Slide n › Kind, where Slide n navigates back to the slide lens — and an actions row, then mounts sections in a fixed order: the kind-specific ones first, then Geometry, Fill and border, Effects, Order. Comment sits in the actions row on every object lens.

A lens holds no copy of anything. A control's value is derived from the body every render; its change handler builds one withSet (or a procedure) and applies it. When an action changes what is selected — Merge, Group, Duplicate, deleting a row — the lens computes the new selection from the edit's resulting body before applying it, then inspects, so the next lens opens on ids that exist.

3

The text-style section, and the three layers it edits

components/text-style.svelte is mounted by the text-box, cell, next-letter, text-selection and speaker-notes lenses with blockId and, optionally, a range and three switches: whole, paragraph, spacing. It edits three layers:

  • The named style the block wears — the first select, writing <block>/style. Changing the style's own fields is the Style panel's job.
  • The block's format — font, size, alignment, vertical alignment, line height, before, after — each writing <block>/format/<field>; the value shown is the block's if set, else the style's, else the default, which is the same resolution the renderer's textSceneOf uses.
  • Marks — B I U S over the range (toggledMark), enabled only when the range is non-empty; a whole-block lens uses the whole text as its range.

FG and BG sit together on one row:

  • FG on a partial range becomes a coloured mark (colouredMark, which first cuts any coloured mark it overlaps); on a whole block it writes format/color. The swatch shows the range's mark colour, else the block's, else the style's; × clears.
  • BG goes where a background lives for that holder: a text box's or shape's <el>/paint/fill, a table cell's <cell>/format/background, and a block with no holder (the notes) its own format/background. The section works that out with holderOf, so the same control is right in every lens.

paragraph={false} drops the alignment rows (notes have no box to align in); spacing={false} drops line height and before / after (cells, notes).

4

Each lens

Slide · inspector/slide.svelte

Title “Slide n”. Edit notes in the actions opens the speaker-notes lens. Sections: Notes (first line and a paragraph / character summary, or “No speaker notes yet”); Slide (Hidden toggle → <slide>/hidden; Background picker with the theme's swatches → <slide>/background, and “Use the theme background” to remove it); Reset to layout (collapsed; puts every box that came from a placeholder back on the placeholder's frame, keeping text). There is no layout picker: a slide is made from a layout and keeps it.

Text · inspector/text-box.svelte

Text style for the whole block; Height — Grow / Shrink / Clip → <el>/overflow; Geometry; Fill and border; Effects; Order; Comment. Grow is what a new text box has and what makes its frame follow its text.

Shape · inspector/shape.svelte

Kind — rectangle, ellipse, triangle, diamond, arrow, callout → <el>/content/shape; Geometry; Fill and border; Effects; Order; Comment; an Origin note when it came from a placeholder. No Text section: typing into the shape (or double-clicking it) opens the caret lens, and clicking the shape's edge from there comes back here.

Line · inspector/line.svelte

Geometry as From, To (fractions), Length in units and Angle; Ends — Start and End each None / Arrow / Dot → <el>/content/ends/*; Border only (no fill); Effects without a corner; Order. The endpoints are dragged on the canvas.

Image · inspector/image.svelte

Source: the source kind, alt text (inline editable, multiline → content/block/alt), and a URL field that on Enter sets content/block/source to { kind: "url", url } or removes it when emptied. A note says project files arrive with the file picker. Geometry; Effects; Order.

Table · inspector/table.svelte

Rows and columns as a grid — Row: Insert / Delete, Column: Insert / Delete — acting at the end (bottom row, rightmost column) through withRowInserted and friends; Delete is disabled at one row or one column. Geometry; Border (no fill — cells have their own); Effects without a corner; Order; Comment. The first row is still drawn as a header by the renderer, but there is no control for the count.

Cell · inspector/cell.svelte

Title “Cell” or “n cells”; crumbs Slide n › Table › Cell, where Table returns to the table lens. Actions: Merge (enabled when the picked cells tile a rectangle) and Split (one merged cell). Sections:

  • One cell: the text-style section for its block (whole, no spacing). Several: an alignment icon row that writes each cell's block format/horizontalAlignment, shown mixed when they disagree.
  • Fill and border: Fill → <cell>/format/background; Border colour + width, and Dash on its own row (disabled at width 0) → <cell>/format/border/*; clearing the colour or setting width 0 removes the border; every write goes to every picked cell with withSets.
  • Size: W and H as a percentage of the table, reading the first picked cell's column and row shares and writing <table>/columnWidths or <el>/content/rowHeights.
  • Rows and columns: Insert below / to the right of the first picked cell (staying in the cell lens); Delete this row / column (returning to the table lens, since the cell is gone).

After a merge the kept cell — the first one picked — is re-selected; after a split, the anchor cell.

Group · inspector/group.svelte

Ungroup in the actions (children go back to slide fractions where they were drawn, then the slide lens opens); Members as rows that select a child; Geometry for the group's frame; Align / Distribute / Order for the children (the arrange section with groupId); Effects without a corner.

n objects · inspector/multi-selection.svelte

Group (disabled if any member is already inside a group), Duplicate, Delete; a Selected list; Align / Distribute / Order relative to the selection or the slide. Group and Duplicate compute what is new from the edit's body before applying, then select it.

Text (caret) · inspector/next-letter.svelte and Text selection · inspector/text-selection.svelte

Both mount the text-style section with the range from the workspace selection — collapsed for the caret, so marks are disabled and FG writes the block; a real range for the selection, so marks and FG act on the range. Crumbs go back to the slide.

Speaker notes · inspector/speaker-notes.svelte

The notes block rendered by the same text engine the canvas uses, editing always on, in a box whose background is the block's own format/background; edits go through replaced. Under it the text-style section with paragraph and spacing off, so it offers style, font, size, FG / BG and marks. “Start notes” inserts an empty block with withNotes.

Comments on … · inspector/threads.svelte

For one object or one slide: a composer (⌘↩ posts through startThread with the right within), the open threads, and a collapsed resolved list. The three store queries are held for the lens's life and refreshed after a post. A thread opens general.comment.

Comment · app-views/general/comment/comment.svelte

A general lens, so any category can open a thread. Open / Resolved chip in the actions; the author as a PanelActor (opens the person lens); the first comment as a quote; Reply and Resolve / Reopen beneath it; Anchored to — the resource title and “Slide n · Shape” — which opens the deck on that slide and inspects the threads lens; replies oldest first; a reply composer. The deck runtime it needs for the anchor label is attached in an effect keyed on the thread's target.

Chart · inspector/chart.svelte

A placeholder that says charts arrive after the analysis chart settles.
