Template Features — Reference

A template belongs to its project. It can be edited in the ordinary document and presentation editors through a copy, made from a live document, a live presentation, or one slide of a presentation, and inserted into whatever is open, which asks what each of its variables should select. Resource sets exist as a subject, and a variable's default can name one. This suite says what was built, how it fits the tree, and every difference from main, file by file.

3

The one-paragraph version

A template is the project's copy of something: a portable body and a list of variables, each with a default that means the whole project unless the template says otherwise. To edit a template you open it: the capability writes its body into a scratch document or presentation and records the stage; the ordinary editor opens on the copy; the editor's Templates panel saves the copy back or discards it, and the copy is the only thing that ever writes the template's body. To make a template you name and save the open document, presentation, or current slide, and it opens for editing at once. To use one, on its own or inside what you have open, you use or insert it: a modal asks what each variable should select, offering its default, and the copy lands with its prompts' scopes already filled. A resource made from a template is its own afterwards and carries no reference back; later changes to the template do not reach it, and a working copy takes no comments.
