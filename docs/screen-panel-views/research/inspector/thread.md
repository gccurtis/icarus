## Thread

Title, editable, plus the three things that define what kind of enquiry it is.

**Shows**

| | |
| --- | --- |
| Title | Why did Feeder 12 fail twice? |
| Mode | Discover · **Question** · Hypothesis |
| Anchor | Q-14 |
| Turns | 3 |

**Needs** — the thread record with mode, anchor and turn count.

**Open** — whether mode can change after turns exist. A Discover thread that
becomes a Question thread has to acquire an anchor from somewhere.

## Agent

Which agent, what it can look up, and what it may do — all set once, for the
thread.

**Shows** — Grid Analyst, then `Scope · Field reports 2024–25 · 96`, `Web · on`,
`Tools · 4 allowed`

Every turn in the thread runs as this agent. There is no per-message persona
switch, and the section says so rather than leaving the absence to be noticed.

**Needs** — the thread's persona reference, its scope, its web flag, and the
persona's tool allowance.

## Note

Research has no Copilot dock. The whole screen is the conversation, so a second
composer floating over it would be two ways to say the same thing.

**Needs** — nothing.
