one and kind is already on the row.

## Project

**Shows**

- *Regulatory filing shell* — Document · 4 variables
- *Board update* — Slide deck · 2 variables
- *Title slide* — Slide · 1 variable
- *Cost model skeleton* — Spreadsheet

**Needs** — project `Template` records with target kind and variable count.

## Global

**Shows** — *Incident review* — Document

**Needs** — global `Template` records.

**Open** — the row does not say whether you may edit a global template. Since that
is a deployment rule rather than a model fact, the panel has to ask something to
find out.

## Panel furniture

The action row: **New**, **Edit**, **Use**, **Duplicate**. A search over templates.

Copying a project template to global scope creates another template. There is no
live shared ownership, so the two diverge from that moment.
