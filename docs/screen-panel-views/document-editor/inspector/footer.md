## Footer

The content, editable, including where the generated page number falls within it.

**Shows** — "Docket 2026-114        2"

**Needs** — the footer furniture content, with a page-number placeholder rather
than a literal number.

## Page number

Generated from page-numbering settings, never typed as content — which is why
this is a section here rather than something you edit above.

**Shows** — `Position · Outside`, `Start at · 1`, `Show on first · off`

**Needs** — the same numbering settings the [Page view](../context/page.md) owns.

**Open** — the setting appears in two places. One has to be authoritative and the
other a mirror, or they will disagree.

## Spacing

Starts collapsed.

**Shows** — `From bottom · 0.5 in`

**Needs** — the footer offset.
