## Link

The target and the text it is on, so a link with misleading text is visible as
such.

**Shows** — `URL · https://nerc.gov/docket/2026-114`, `Text · the 2026 docket`

**Needs** — the link mark's target and the text it covers.

**Open** — an internal link, to another resource in the project, is a different
thing from a URL. Whether both are the same mark needs deciding.

## Actions

**Open**, **Copy**, **Remove**.
