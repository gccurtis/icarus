# Project Overview — panels

The permanent first tab. Who is here, what is addressed to you, what exists, and
the four things you can make. Every list on this screen is a project-scoped
query, never a stored array on the project.

One subscreen. There is nothing to switch between.

## Context panel

| View | What it is for | Sections |

| [Overview](context/overview.md) | The project itself — what it is, who is in it, what needs you | This project · State · Here now · Needs you · Dates |

## The rule this screen keeps

A row is a thing, not a health report. There is no Status column on the work
table: something that cannot proceed appears in Health and in the status bar, and
everything else is left to be what it is.
