# New Tab — panels

One question: which editor do you need? Three things to make, plus what you
already have. Research, Analysis, Context, Templates, Personas and Automations
are not here — they are permanent tabs and are never not open.

One subscreen.

## Context panel

| View | What it is for | Sections |
| --- | --- | --- |
| [Create](context/create.md) | The three editors, as a list | Editors |
| [Recent](context/recent.md) | What you had open, and what changed | Today · Yesterday · Earlier |
| [Templates](context/templates.md) | Starting from something rather than nothing | Document · Slide deck · Spreadsheet |
| [Bring in](context/bring-in.md) | Getting outside material into the project | Upload · Your connectors · Add a connector |

Bringing content in lives in the panel rather than the centre because it does not
open an editor, which is the only question this tab asks.

## The rule this screen keeps

The tab becomes the thing. Creating a document turns this launcher into that
document rather than opening a second tab, and opening something already open
activates that tab and closes this one.
