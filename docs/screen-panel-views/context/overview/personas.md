## This persona

Picture, name, and what it does — the one-line description that also appears
wherever it is named as an actor.

**Shows** — Grid Analyst, `Does · Reads field data and relay logs`,
`Available in · This project`

**Needs** — the `Persona` record with avatar, name, description and scope.

## Record

What it has actually done, as three numbers. It leads the configuration below
because a record is what tells you whether to trust an agent.

**Shows** — `41 tasks · 2 running · 128 findings`

**Needs** — a per-persona aggregate over `AgentTask` and accepted `Finding`.

**Open** — no such aggregate exists. Task counts and a findings-accepted tally
both need one.
