## Templates

The concept, in two sentences, because "template" means something slightly
different in every application: an ordinary body with some of it left open, and
authoring one is authoring a document, a deck or a spreadsheet.

**Needs** — nothing.

## In this project

Counts by kind, which is also the fastest way to notice the project has no deck
template.

**Shows** — `Templates · 5`, `Documents · 1`, `Slide decks · 2`, `Single slides · 1`,
`Spreadsheets · 1`

**Needs** — project `Template` records grouped by target kind.

## Available everywhere

Global templates, counted separately because they are not this project's to edit.

**Shows** — `Templates · 1`

A global template can be used here; who may edit it is a deployment rule, not
something the absence of a project says.

**Needs** — global `Template` records.

**Open** — global-template edit authority is undefined by the model.

## Selected

The current selection, with the two things you do with it.

**Shows** — `Name · Regulatory filing shell`, `Variables · 4 required`, with
**Open** and **Use**

**Needs** — the selected template. **Use** is disabled while variables cannot be
placed.
