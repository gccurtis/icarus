## Findings

Findings are resources and can be retrieved, which is why they are here.
Questions and hypotheses are organisational and cannot be named by a rule — that
distinction is the reason this list is not simply "everything".

**Shows** — *Undergrounding cut SAIDI 38%* · 14

**Needs** — accepted `Finding` records.

## Connector files

Connectors, standing for the files they synced.

**Shows** — *SharePoint — Ops Reports* — 312 files

**Needs** — `Connector` records with file counts.

**Open** — whether this view lists connectors or their files. A list of 312 files
is unusable; a list of connectors hides what is actually in scope.

## Panel furniture

usually looking for one named thing rather than browsing a category.
