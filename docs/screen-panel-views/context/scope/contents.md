## Problems

Anything the resolver could not do.

**Shows** — *One named resource no longer exists* — `d_88a2` · kept as written

The rule is kept exactly as written rather than silently repaired, so a missing
resource is visible instead of vanishing.

**Needs** — unresolved descriptors from the resolver.

**Open** — this depends on the resolver contract for missing named resources,
which does not exist yet.

## Unsaved changes

What the current edits would do, before saving. A scope is used by other things,
so the difference between "what I have set up" and "what is live" has to be
visible.

**Shows** — *Interconnect Failure Review* — Would be added; *Regulatory filing
shell* — Would be taken out

**Needs** — a diff between the edited definition and the saved one, resolved.

## Contents

Everything that survives, each row opening its own lens with an *In because*
explanation.

**Shows** — *Q3 Resilience Memo*, *Board Update — October*, *Outage Cost Model* · of 211

**Needs** — a paged resolve, and per-result expression proofs so each row can say
which term put it there.

**Open** — *In because* needs those proofs from the resolver. Without them the
column is a guess.
