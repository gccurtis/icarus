# People

| View | What it is for | Sections |
| --- | --- | --- |
| People | Everything that can appear as "who did this" | Here now · Everyone · Agents and machinery |

Anything that can be named as an actor is listed here and can be inspected. Only
a person can be written to; the panel says so at the foot rather than leaving the
difference to be discovered.

Searchable across all three sections.
