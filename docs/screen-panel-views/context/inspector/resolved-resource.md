## In because

Which term put it here, traced back through whatever it came through.

**Shows** — "**Regulatory corpus** includes SharePoint — Ops Reports, which
produced this file." — plus a line noting that a connector expands to the files it
synced, and that the connector record itself is not retrievable content.

**Needs** — per-result expression proofs from the resolver.

**Open** — this is the gap that gates the whole *In because* column. Without
proofs, the explanation would have to be reconstructed client-side, which for a
nested reference is guesswork.
