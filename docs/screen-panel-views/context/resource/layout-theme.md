# Theme — editing a layout

| View | What it is for | Sections |
| --- | --- | --- |
| Theme | What this layout takes from the deck theme, and what it overrides | Background |

A layout inherits the deck theme unless it overrides it. This view is where an
override is made, and where inheritance is visible when there is none.

## Background

**Shows** — `Kind · Solid`, `Colour · Paper`, with a line saying the value is
inherited unless changed.

**Needs** — an optional background override on the layout, distinguishable from an
inherited value.

**Open** — only background is offered. Whether a layout can override type or
palette as well is undecided; if it can, this view needs those sections and a
clear indication of which values are inherited and which are set.
