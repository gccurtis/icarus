# Insert

| View | What it is for | Sections |
| --- | --- | --- |
| Insert | Putting something new into the document | Basics · Content · Data and AI · Structure |

Where the toolbar's insert menu went. Grouped by what the thing is, not by how
often it is used, so the list stays stable as it grows.

Every entry inserts at the current position and then selects what it inserted, so
the inspector immediately shows the thing you just made.

## Basics

**Shows** — Text block · Heading · List · Checklist

**Needs** — the block kinds the document body supports.

## Content

**Shows** — Image · Table · Embed

**Needs** — as above.

**Open** — an embed's permitted sources are undefined.

## Data and AI

**Shows** — Formula · Prompt block · Variable

*Variable* inserts a reference to a project variable inline; *Formula* inserts an
expression that may refer to one. They are separate entries because they are
different acts, and the panel says which is which on the row.

**Needs** — inline formula and prompt-block entities, and the project variable
list.

## Structure

Layout structure rather than content. Starts collapsed.

**Shows** — Divider row · Explicit page break · Side-by-side row

**Needs** — row and break entities in the body model.
