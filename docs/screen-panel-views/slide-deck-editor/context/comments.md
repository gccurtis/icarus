## Scope chips

Three chips: the whole deck, this slide, or the selected element.

**Shows** — `Deck` · `Slide 4` · `Element`

**Needs** — comment anchors at deck, slide and element granularity.

**Open** — whether a comment can anchor to an element at all, or only to a slide.
The document editor anchors to a text range; a deck's equivalent is not settled.

## Open

**Shows** — Tomas Kaur — "@ana is this the chart you wanted…" — 4h

**Needs** — `Comment` threads for this deck, with author, body, time, anchor and
mention detection.

## Resolved

Starts collapsed, and says "nothing resolved yet" rather than showing an empty
box.

**Needs** — resolved state on the thread.
