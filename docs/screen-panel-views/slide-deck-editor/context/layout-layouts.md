## In this deck

Each layout with what it is made of and how much depends on it. The "used by"
count is the important number: it is how many slides an edit here will change.

**Shows**

- *Title and two panes* — 3 placeholders · 2 locked · used by 4
- *Title slide* — 2 placeholders · used by 1
- *Section break* — 1 placeholder · used by 2
- *Full-bleed chart* — 1 placeholder · used by 1
- *Blank* — no placeholders

**Needs** — the deck's layouts with per-layout placeholder and locked counts, and
a count of slides referencing each.

## Panel furniture

The action row: **New**, **Duplicate**.

Deleting a layout is absent.

**Open** — deleting a layout that slides use has no defined outcome. Either those
slides fall back to Blank, or deletion is refused, or the layout is retained as a
tombstone.
