## Theme

**Shows** — `Background · Paper`, `Font · IBM Plex Sans`, `Palette · four swatches`

**Needs** — the deck theme: background, type family, and an ordered colour set.

**Open** — how many colours a theme has, and what each one is *for*, is
undetermined. Four unlabelled swatches cannot be assigned to anything.

## Named styles

Deck typography, as named styles rather than per-element overrides — the same
principle as the document editor. Starts collapsed.

**Shows** — *Slide title* — 24/32 · 600; *Body* — 13/20 · 400; *Caption* — 10/14 · mono

**Needs** — the deck's `StyleSet`, keyed by style key so a layout placeholder can
name one.
