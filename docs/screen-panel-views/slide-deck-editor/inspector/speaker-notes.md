## Notes

The content, editable.

**Shows** — "Lead with the relay finding, not the spend. If asked about the 2024
precedent, the docket number is in the appendix."

**Needs** — the slide's notes content.

## Note

Notes use the same block editor as everything else and never appear on the slide
canvas.

Worth stating because the block editor is the thing that makes them feel like
slide content when they are not.

**Needs** — nothing.

**Open** — this lens duplicates the Speaker notes section of the
[slide lens](slide.md). Whether both should exist is a review question; the
answer is probably that this one is the editor and the slide lens links to it.
