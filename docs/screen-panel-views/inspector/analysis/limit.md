## Limit

How many, out of how many there are. Both numbers, because one without the other
says nothing.

**Shows** — `Keep · top 10`, `Of · 41 groups`

**Needs** — the limit value and the ungrouped result size.

## Note

The limit is shown next to the chart as well as here, so a truncated view is
never mistaken for the whole.

Worth a section because a bar chart of the top 10 looks exactly like a bar chart
of everything.

**Needs** — nothing.

## Actions

**Remove**.

**Open** — "top" depends on the sort. A limit with no sort is arbitrary, and the
panel should either require a sort or say what order it falls back to.
