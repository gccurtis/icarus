## Hypothesis

The statement, the human's assessment of it, and a confidence.

**Shows**

| | |
| --- | --- |
| Statement | The relay coordination study was never redone after the 2024 reconductoring. |
| Assessment | Testing |
| Confidence | 0.70 |

Assessment is an explicit human judgment. It is never calculated from the count
of supporting and contradicting findings, and the section says so — because a
screen that shows both a tally and an assessment invites exactly that inference.

**Needs** — `Hypothesis` statement, assessment and confidence.

**Open** — who set the confidence and when. A bare 0.70 with no author is not
interpretable.

## Evidence

Findings on both sides, each marked with how it bears.

**Shows** — *Relay pair mis-coordinated since 2024* — Supports; *2024 study index
lists a revision* — Contradicts

**Needs** — `ResearchLink` rows from findings to this hypothesis, with bearings.

## Note

Bearing lives on each finding-to-hypothesis relationship, not on the finding —
because the same finding can bear differently on different hypotheses. Starts
collapsed.

**Needs** — nothing.
