## Binding

**Shows** — `Name · analyst-default`, `Default · Yes`

**Needs** — the model binding on the persona, and the list of bindings available.

**Open** — where that list comes from. Bindings are deployment configuration, not
project data.

## Boundary

A binding name only. Providers, credentials and deployment setup belong outside
the project workbench.

Stated as a section because this is exactly the place where a settings screen
would grow if nobody said otherwise.

**Needs** — nothing.
