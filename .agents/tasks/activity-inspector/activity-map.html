What an activity actually is.

The inspector does not infer an event from a file diff. It reads a frozen activity row, turns its stored verb into the “What” label, and treats its stored target as “Where.” This page traces that path and the current producers.

End-to-end

The data path

The capability that performs work chooses the verb and target. The Project capability validates and scopes the saved row; the panel only formats it.

User or agent action

Upload, rename, move, delete, update dataset context, or finish a grounded agent task.

Capability writes

The owning mutation creates an activity row in the same Store transaction as its durable change.

Project projection

activityOf admits exact fields, scopes by project, resolves the current actor, and preserves historical labels.

Panel renders

activityLabel(verb) becomes “What.” target.label becomes “Where,” with optional context below.

Persisted contract

One immutable activity row

projectId
Owning project; server scope filters on this.
actor
Structured user, agent, connector, or system identity.
actorLabel
Historical snapshot of the display name at event time.
verb
Free text chosen by the producer. It is not a closed enum.
target
{ kind, id, label } — the primary “Where” snapshot.
context?
Optional second snapshot; External Files uses the path here.
detail?
Optional bounded prose shown beneath “What.”
Boundary

The row is deliberately wider than “file”

Targets may name documents, spreadsheets, research chats, findings, tasks, connectors, personas, automations, comments, or other future project events.

A label survives deletion. An ID in old history is evidence, not proof that something can still open.

Projection

How “What” is produced

The inspector uses a four-entry vocabulary map and a simple fallback. It does not inspect the target kind to invent a different verb.

Inspector transformation

stored verb→trim + lowercase lookup→known label or capitalize first character
asked
Started a research question
accepted a finding on
Accepted a finding
commented on
Added a comment
connected
Connected a data source
anything else
Trim it, then uppercase only the first character.

The three surfaces do not use identical wording

Overview feed
actorLabel + raw verb, with target label on the next line.
History panel
activityLabel(verb) + ": " + target.label.
Inspector
activityLabel(verb), then detail. For research + asked, it quotes the target label as the question.

Example: context-updated currently displays as “Context-updated.” The producer supplies the raw verb; the inspector does not turn the hyphen into prose.

Implemented behavior

When “Where” becomes a link

The historical target is resolved against the current, server-scoped resource index by exact ID and normalized kind. A label or path never chooses a destination.

documentDocument editor · exact resource IDOpens
presentationPresentation editor · exact resource IDOpens

external-fileExternal Files singleton + exact file inspectorOpens
findingNo content editor exists; keep the Project resource lensInspects
task / connector / persona / automationNo resource destination is defined in this changeText
missing / deleted / unavailableFrozen label and context remain readableText
Safety rule

Historical target ≠ current destination

A current link appears only when the scoped index contains the same ID and corresponding kind. This prevents a deleted research event from silently opening the newest chat and prevents malformed history from crossing resource types.

External Files maps stored external-file to the index’s UI taxonomy file. It then uses the existing stable-library inspection procedure.

Audit notes

What this trace clarifies

Confirmed

“What” is producer-controlled

The stored free-text verb is the source. The panel recognizes four phrases and applies a minimal capitalization fallback.

Names are intentionally historical

actorLabel and target/context labels remain as they were when the event occurred, even after rename or deletion.

Current actor and historical actor can differ

The feed uses the historical actor label. The Who link resolves the current actor and may show its current label.

Gaps left visible

Most demo verbs have no writer

Editor changes, comments, connectors, research questions, task starts/reviews, personas, and automations do not currently create the seeded Project activity events.

Search uses raw values

History searches asked, not the displayed phrase “Started a research question,” unless another stored field happens to match it.

Activity is a summary, not a diff

There is no general structured metadata or revision payload. External Files supplies small detail strings; agent completion supplies none.
