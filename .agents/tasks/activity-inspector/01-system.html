What exists today.

Two capabilities write rows. Seven product surfaces read them. The saved verb is open text, and each surface decides how much formatting to apply.

01

The pipeline

1 · Product mutationExternal Files or Agents

The feature decides that an event is worth recording.

2 · Row creationStore transaction

The producer supplies actor, verb, target snapshots, and optional prose.

3 · Project projectionactivityOf

The server validates fields, applies project scope, and resolves current actors.

4 · View formattingactivityLabel

The view turns the verb into What and the target snapshot into Where.

projectId
Owning project; every read projection scopes on it.
actor + actorLabel
Structured identity plus a historical display-name snapshot.
verb
Any string supplied by the producer. There is no central catalog.
target
{ kind, id, label }, preserved even if the target is later deleted.
context?
An optional second target snapshot; External Files uses it for the path.
detail?
Optional bounded prose shown beneath What.

Agents task is not Research Chat

The task writer runs a persona against project evidence and publishes a task result. Creating or using a Research Chat does not write an activity row today.

No undo dependency

Undo and redo remain local to document, presentation, and spreadsheet editor state. No undo command queries, creates, or replays activity rows.

05

Current rendering inconsistency

Four special labels

asked, accepted a finding on, commented on, and connected get custom phrases. Every other verb is only trimmed and capitalized.

Different consumers, different prose

Overview and Agents display raw verbs, History and the Activity inspector use the shared formatter, and the Person inspector maintains another local label map.
