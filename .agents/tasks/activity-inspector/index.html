Activity inspector · direct answers

Activity is history for viewing.

It is an append-only project audit feed. It does not power undo, redo, file restoration, or state reconstruction. The current feed is useful, but its producers and vocabulary need a tighter contract.

Answers to the questions

Is Activity connected to global undo?

No. Activity rows are saved history and read by project and library views. Editor undo and redo live in each editor’s client runtime and never read or write the activity table.

activity table + project projections · editor client runtime histories

Is it worth keeping?

Yes, if the feed only records useful events. Overview, Project History, two activity inspectors, resource details, person details, and External Files history depend on it. Removing it would erase useful history from seven product surfaces. An empty feed is still better than invented or vague entries.

See 01 Current system for every direct reader.

Where did “Reviewed” come from?

Seed data only. No production code currently records a reviewed activity. The seeded row points at an Agents task and includes a reviewer, but it is a demonstration fixture rather than evidence of a live review event.

app/seed/activity.json · no matching production writer

What about “Started” and “Recalculated”?

They are also seed-only examples. started is attached to a seeded automation. recalculated is attached to a spreadsheet and names an agent-task actor that is absent from the task seed. Neither has a current trigger.

app/seed/activity.json

What does “Asked a question” mean?

The friendly label comes from the stored verb asked, but that row is seed-only. Research Chat does not currently write activity. Agents tasks are a separate feature: a task can run a persona against project evidence, while Chat creates a research thread.

create-chat.ts · execute-agent-task.ts · activity-label.ts

What production events exist?

External Files records uploads, re-uploads, renames, moves, context changes, and deletions. Agents records answered or found insufficient evidence for when a task finishes. The latter is a result status presented as activity and should be removed from the feed.

recordExternalFileHistory · executeAgentTask

How is “What” made?

The producer saves a free-text verb. The inspector recognizes four values and otherwise capitalizes the first character. This is why specific prose such as “Uploaded 28 KB” is useful while “Reviewed” or “Found insufficient evidence for” lacks context.

activityLabel(verb) · the target kind does not affect the wording

What should Where do?

Native project resources open their editor. External files open External Files with the exact file selected. Personas, tasks, and automations open their exact Agents detail. Findings and connectors show a clear “not wired yet” alert. A target that no longer exists remains readable and says it is missing, deleted, or otherwise unavailable.

Implemented in this worktree and covered by Chromium navigation tests.

Recommendation

Keep Activity, replace producer-owned free-text verbs with an Activity-owned typed event catalog, derive all visible wording from structured payloads, and reseed only events the product can actually emit.
