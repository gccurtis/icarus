# Model choice, by cast

Date: 2026-07-29

Generated by [dev-test/model-report.sh](../../dev-test/model-report.sh) from one
`run.sh intelligence` log per candidate. Every number is measured: token counts
are the provider's own per-call usage, cost is those counts at each model's
published rate.

A **cast** is what the application asks for — `purpose/strength/speed/cost`.
Code never names a model; configuration maps each cast to one. So "which model
is best" has one answer per cast, not one answer overall, and this document is
organised that way.
