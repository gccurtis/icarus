Every number is measured. Token counts are the provider's own per-call
usage, captured at the intelligence boundary. Cost is those counts at each
model's published rate.

The **cast** is what the application asks for — `purpose/strength/speed/cost`.
Which model serves a cast is configuration, so the per-cast tables below are
where a model choice is actually decided: a model can win at one cast and lose
at another, and an average over both would hide that.
