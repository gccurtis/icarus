# Route and scope inventory

This is the executable inventory of every installed HTTP route. The generated
section is derived from the route source and the actual dispatch maps; it is not
a separately maintained registry. The acceptance gate fails when a route lacks
an owner, scope, dispatch contract, response-reference description, mutation
contract, error/redaction classification, or completion-packet owner.

The current scope labels describe what the server enforces today:

- `public`: no authenticated subject.
- `user`: authenticated user context only.
- `organization_admin`: authenticated user plus an organization-role check in
  the handler.
- `project_directory`: authenticated user plus a project membership or action
  check in the handler.
- `project_execution`: authenticated user and an authorized project injected
  by the project middleware.
- `operator`: development/operations surface whose narrower operator contract
  is completion work.

Known fail-open, caller-blind, and source-admission seams are deliberately
called out in the error-contract column and assigned to a completion packet.
Their presence does not make the baseline safe; their explicit ownership makes
silent drift fail.
