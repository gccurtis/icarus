# Omega completion matrix

This is the version-pinned definition of backend completion at actual starting
commit `c0d072556919048b495e729736cf78a7d28e68d3`. It records current truth, not
the state hoped for by a target specification. Each numbered packet appears in
exactly one row. A packet updates its row as behavior ships; it does not replace
this baseline silently.

State has a strict meaning:

- `shipped`: invoked, wired behavior with current contract evidence.
- `partial`: usable behavior exists, but the target contract still has owned
  gaps.
- `missing`: target-only behavior with no usable current implementation.
- `in-flight`: active code is on a different branch and is not main evidence.
- `superseded`: present/prototype behavior conflicts with the target model and
  must be migrated, not blessed.

The “evidence / target” column points to representative seams. The generated
[route inventory](route-scope-inventory.md) is the exhaustive HTTP/dispatch
list, and the generated [persistence inventory](persistence-inventory.md) is the
exhaustive store list.

## Explicit V1 exclusions

The accepted exclusions are maintained in
[`accepted-deferrals.md`](accepted-deferrals.md): audio/video/transcription,
legacy XLS and executable workbook content, slide animation/transition fidelity,
editable PDF import, commercial libraries, organization-owned library masters,
and distributed placement before it is needed. They are not represented as
missing capabilities in this matrix.

## Coverage rules

- The acceptance script compares the 44 rows above with the 44 executable work
  packet filenames.
- It compares every package returned by `go list ./core/capability/...` with the
  service-package text above. Formula and `formula/names` are intentionally
  separate packages.
- The remaining ingest finding is `ING-3` (connector admission). `ING-1`,
  `ING-2`, and `ING-4` are closed by Ω-003 / record 0165; `ING-5` and `ING-6`
  are closed by Ω-005 / record 0167.
- `workspace-capability` and `origin/feature/slides` are evidence of separate
  work only. Neither branch is merged or rewritten by this packet.
