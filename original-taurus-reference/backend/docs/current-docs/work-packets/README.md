# Taurus Omega execution packets

These 44 files are the coding-agent handoffs. Point an agent at one file; do not assemble a separate prompt.

Suggested instruction:

> Execute `docs/current-docs/work-packets/omega-NNN-….md` completely. Begin only after its hard predecessors are present on `main`. Follow its required reading, decision boundaries, validation, change-record, and direct-to-main commit contract.

## Sequencing rules

- One packet normally maps to one numbered change record and one scoped commit pushed to `origin/main`.
- Start from the latest `main`, not the frozen planning SHA.
- Hard predecessors must be present on `main`. A later-packet integration reference is not a start blocker.
- Ω-035–Ω-037 implement format behavior against the File/Object port; Ω-042 later supplies and re-certifies production storage adapters. This deliberately avoids a circular dependency.
- Ω-018 may land its Project Overview Task section as typed-unavailable before Ω-019, then must be re-certified after Ω-019.
- Ω-042 consumes the canonical schemas from Ω-001–Ω-041. Ω-043 packages them. Ω-044 is final certification.
- Do not claim completion based on code alone: the packet's acceptance criteria, tests, migration/rollback evidence, security analysis, and repository gates all apply.
