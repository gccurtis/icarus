# Implementation checklists

These checklists are the live progress layer for support roadmaps.

## How to use them

- Keep exactly one roadmap item marked as the current focus.
- Check an item only when its implementation, tests, current-state
  documentation, companion documentation, and change record are complete.
- Update the relevant checklist in the same commit as the work it records.
- Add links to the completing change record rather than duplicating its
  rationale here.
- Split a checklist only when a track becomes too large to scan quickly.
