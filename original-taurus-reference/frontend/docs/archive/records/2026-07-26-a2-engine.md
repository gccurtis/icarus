# A2 (1/3) — block-kind engine: code / callout / divider

The engine for A2's structural kinds — registry, ProseMirror schema, Omega↔PM bridge,
runtime actions, and rendering. No inspector wiring yet (that is commit 2); this commit
makes code/callout/divider round-trippable and the two conversion/insert actions callable.

## Single source of truth: `block-kinds.ts`

```ts
export const blockKinds: Record<BlockKind, BlockKindMeta> = { … };
export const textTypeOptions;      // Body + Heading 1-6
export const insertElementOptions; // Divider, Code, Callout, Prompt
export const isDataKind, isLeafKind, blockKindLabel;
```

A new registry (`systems/documents/block-kinds.ts`) holds every kind's label, menu group,
and structural facts (text-bearing / leaf / data-carrying). The schema mapping, bridge
diff rules, inspector menus, and CSS all derive from here — no per-kind knowledge scattered.
`types.ts` gains the full 14-kind `BlockKind` union and an `ImageData` type (mirrors Omega;
unused until the image pass).

## Hybrid ProseMirror schema

```ts
code_block: { content: 'text*', marks: '', code: true, defining: true, … }   // literal, no marks
divider:    { atom: true, selectable: true, … toDOM: ['hr'] }                 // leaf, no content
paragraph:  toDOM(node) => ['p', kind !== 'paragraph' ? { 'data-kind': kind } : {}, 0]
```

`callout`/`quote` reuse the paragraph node (via `kind`, like `prompt`) — same content
model, styled by `[data-kind]` CSS. `code` and `divider` have genuinely different content
models, so they get their own nodes. Node type follows content model, not visual style.

## Bridge mapping + two diff rules

```ts
// blockNode: code→code_block, divider→divider, else paragraph(kind)
// nodeKind:  code_block→'code', divider→'divider'
const leaf = isLeafKind(it.kind);
const newAtoms = leaf ? [] : [{ … text: it.text }];              // divider carries no atoms
const data = it.kind !== pb.kind && !isDataKind(it.kind) ? undefined : pb.data;  // drop stale data
```

`blockNode`/`nodeKind` map the new kinds; the diff emits no atoms for leaf kinds and drops
a block's typed data when its kind changes to a non-data kind (Omega self-heals on reload,
but this keeps the local snapshot clean). Unit-tested in `bridge.test.ts` (round-trip per
kind; divider→no atoms; code→atoms+no marks; kind change→data dropped).

## Runtime actions: `setTextType` + `insertElement`

```ts
setTextType(kind)  // convert every block the selection touches (whole-line, one set_block each)
insertElement(kind) // insert divider/code/callout/prompt — replace an empty line, else after it
```

`setTextType` is whole-line (no split-at-bounds); `insertElement` builds a fresh node (null
blockId) so the differ emits `insert_block` with the right kind. Added to the `EditorActions`
contract in `session.ts`. Kind CSS (blockquote/callout box/code `pre`/`hr`) lands in
`DocumentStage.svelte`; `inspector.ts` height floors cover the new kinds.
