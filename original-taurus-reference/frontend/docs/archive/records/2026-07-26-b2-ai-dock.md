# B2a — un-mock the AI Quarterback dock (real chats / turns / tasks)

Replaces the mock AI-agent conversation store with Omega's real **chat + agent-task**
API. The dock is now a genuine conversation surface: create/open chats, send turns
(optimistic user turn → real reply), and — for `action`/`plan` turns — poll the
spawned task's live state, working list, and reviewable plan draft, with a real
**Accept plan** action.

This is the block-model-independent B2 work (re-ordered to run first). **B2b** adds the
persona-default picker, a per-turn Web toggle, and badges the non-backable context
sources; both were approved as a follow-up.

## Architecture (chat-centric, per the approved design)

- **New client `systems/ai-agent/api.ts`** — the only place raw Omega JSON lives.
  - Chats: `listChats(resourceId?)`, `createChat(mode, resourceId?, title)`,
    `getChat(id)`, `postTurn(id, message, web)` → `GET/POST /agent/chats`,
    `GET /agent/chats/:id`, `POST /agent/chats/:id/turns`.
  - Tasks: `getTask(id)`, `acceptPlan(taskId, planId)` → `GET /agent/tasks/:id`,
    `POST /agent/tasks/:id/plans/:planId/accept`.
  - Mappers (`toAiChat`/`toAiMessage`/`toAiTask`) translate to UI shapes; `role`→`author`,
    latest plan revision wins, todos/failure flattened.
- **Async store + actions** — `store.ts` seeds empty and keeps strict project isolation;
  `actions.ts` drives it: `loadChats`, `selectAiChat` (loads turns + resumes polling),
  `submitAiPrompt` (reuse-open-chat-when-mode-matches, else open fresh; optimistic user
  turn replaced by server turns), `trackTask` (a `pollToken`-guarded loop to a terminal
  state), `acceptAiPlan`. All async paths guard on `activeChatId` so navigating away
  mid-flight can't clobber another conversation.
- **Rewired components** — `QuarterbackDock.svelte` sends via the real submit and pins
  new chats to the active resource (`setActiveResource`); `QuarterbackPanel.svelte`
  renders the real chats list, conversation, task card (state + todos + failure), and
  plan draft + Accept. The `MockBadge` and "execution remains mocked" copy are gone;
  `mocks.ts` is deleted.

## Honest gaps (nothing hidden)

- **Persona per-chat isn't backable** — chat turns resolve the requester's *default*
  persona server-side (`ChatReplyRequest` carries none). Turns already run under the real
  default; the picker that *sets* the default is B2b.
- **Context sources** — only `document` (the chat's pinned resource) and `web` (the turn's
  `web` flag) reach the backend; `selection`/`knowledge`/`sources` toggle locally and get a
  not-yet-applied badge in B2b.
- **Attachments** — Omega now has them (`/agent/chats/:id/attachments`), but the File/Folder
  buttons stay a tracked mock until the dock wires them (B2b).
