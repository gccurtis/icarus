# Notion frontend reference index

This is the curated map of prior Taurus frontend material. It keeps the historical work easy to reach without copying obsolete architecture into Alpha as present-day law.

## How to read the corpus

- Design and product interaction documents are strong directional references.
- Taurus Omega documents govern the current frontend/backend authority boundary.
- Original Taurus and Taurus Nova implementation documents are historical. Preserve useful product behavior, state vocabulary, and UX reasoning; do not inherit universal event runtimes, translator graphs, Preact-specific seams, or old service wiring by default.
- A page marked Draft in Notion is evidence of prior thinking, not an accepted Alpha contract.
