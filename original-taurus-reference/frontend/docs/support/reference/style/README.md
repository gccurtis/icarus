# Taurus style system

> Status: historical design baseline (reference / non-authoritative). The authoritative, implemented style spec lives in [`docs/style/`](../../../style/README.md) and matches `src/app.css`; this corpus preserves the original design direction and rationale. Deliberate changes are expected as working Alpha surfaces and Omega contracts provide better evidence.

The styling mandate is to make Taurus feel like an **angelic citadel built from astro-tech**: luminous, calm, precise, structurally obvious, and easy to think in.

This is not a demand for literal religious imagery, ornamental futurism, or a single finished visual treatment. It is a discipline for light, structure, elevation, legibility, restraint, and quiet power.

## North star

**Intuitiveness means the product is easy to think in.** The interface should make the next plausible action mentally available without requiring Taurus-specific rituals, hidden gestures, or memorized commands.

## Governing principles

1. **The work surface is sacred.** The center stays calm, spacious, and legible.
2. **Disclosure is product architecture.** Show primary actions; group secondary actions under predictable abstractions.
3. **Recognition beats recall.** Prefer labels, visible state, examples, and stable placement.
4. **Intelligence stays out of the way.** AI appears as useful work, quiet live objects, explicit scope, and reviewable change—not constant solicitation.
5. **The future is calm, not neon.** Precision, depth, responsiveness, and restraint create the futuristic character.
6. **Trust is visible.** Derived and agentic work is attributable, inspectable, reversible, and explicit about state.

## Theme direction

The historical corpus nominated Celestial Light as the default and Eclipse as a first-class blue-black alternate. The current scaffold boots into a dark proof-of-life surface. Treat the actual default as provisional until the first real shell and editor vertical can be evaluated; the smoke-test page alone is not product authority.

Whichever default emerges, the futuristic quality should come primarily from spatial clarity, responsive behavior, and visible intelligence—not decorative glow.

## Status

These documents preserve the design direction and useful starting values. Use them by default, test them against real vertical slices, and revise them deliberately when the working product exposes a better answer.
