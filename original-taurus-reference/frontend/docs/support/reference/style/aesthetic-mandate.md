# Aesthetic mandate

Taurus should feel like an angelic citadel in the clouds operated through astro-tech. The experience is a clear chamber for thought: powerful enough to coordinate documents, knowledge, formulas, agents, and live outputs, but arranged so complexity feels mentally weightless.

## Aesthetic thesis

- **Luminous order:** pearl and off-white surfaces, low-glare depth, restrained blue-violet light.
- **Architectural clarity:** strong spatial zones, calm boundaries, predictable panels, repeatable hierarchy.
- **Instrument precision:** crisp controls, exact focus, readable data, and complete interaction states.
- **Invisible intelligence:** AI appears through resolved work, suggestions, live objects, explanations, and reviewable changes.
- **Reversibility and trust:** material action is attributable, inspectable, recoverable, and honest about uncertainty.

## It should not feel like

- a generic SaaS dashboard;
- an Apple white-and-blue clone;
- saturated cyberpunk;
- a command line disguised as a GUI;
- an expert-only editor built around secret shortcuts;
- a chat product that makes the work surface secondary.

## Design laws

1. Center first: reduce chrome intensity before reducing work-surface clarity.
2. Few things visible, right things visible: primary actions and context remain present; secondary actions are grouped predictably.
3. No secret essentials: shortcuts and context menus accelerate visible paths; they never replace them.
4. Panels are cognitive instruments: context is a map, inspector is a lens.
5. Intelligence is quiet until directed: prompt blocks, review surfaces, status, and the AI Agent carry intelligence without interruption.
6. Beauty is legibility: the user knows what they see, what is selected, what changed, and what comes next.

## Visual metaphors

- **Citadel:** clear zones and structural hierarchy without boxed-in clutter.
- **Cloud:** softness and air at the background level, precision at the control level.
- **Star map:** restrained semantic color provides orientation.
- **Instrument:** every interaction has clear idle, hover, focus, selected, pending, success, failure, and disabled states.

## Review test

A screen succeeds when a first-time user can identify the work surface, context, inspector, selected object, and likely next action within seconds. It should remain understandable when color is removed and should grow calmer—not more cluttered—as its logic becomes familiar.
