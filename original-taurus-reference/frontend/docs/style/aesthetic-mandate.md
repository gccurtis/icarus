# Aesthetic mandate (authoritative)

> Status: **authoritative — committed stance.** This is the aesthetic Taurus
> Alpha commits to. It sets no concrete token values; those live in
> [color](color-system.md), [typography](typography-system.md), and
> [surfaces](surfaces-components-motion.md). Full rationale:
> [reference baseline](../support/reference/style/aesthetic-mandate.md).

Taurus should feel like an angelic citadel in the clouds operated through
astro-tech: a clear chamber for thought, powerful enough to coordinate documents,
knowledge, formulas, agents, and live outputs, yet arranged so complexity feels
mentally weightless.

## Aesthetic thesis

- **Luminous order:** pearl and off-white surfaces, low-glare depth, restrained
  blue-violet light.
- **Architectural clarity:** strong spatial zones, calm boundaries, predictable
  panels, repeatable hierarchy.
- **Instrument precision:** crisp controls, exact focus, readable data, complete
  interaction states.
- **Invisible intelligence:** AI appears through resolved work, suggestions, live
  objects, explanations, reviewable changes.
- **Reversibility and trust:** material action is attributable, inspectable,
  recoverable, and honest about uncertainty.

## It should not feel like

- a generic SaaS dashboard;
- an Apple white-and-blue clone;
- saturated cyberpunk;
- a command line disguised as a GUI;
- an expert-only editor built around secret shortcuts;
- a chat product that makes the work surface secondary.

## Design laws

1. **Center first:** reduce chrome intensity before reducing work-surface clarity.
2. **Few things visible, right things visible:** primary actions and context stay
   present; secondary actions are grouped predictably.
3. **No secret essentials:** shortcuts and context menus accelerate visible paths;
   they never replace them.
4. **Panels are cognitive instruments:** context is a map, inspector is a lens.
5. **Intelligence is quiet until directed.**
6. **Beauty is legibility:** the user knows what they see, what is selected, what
   changed, and what comes next.

## Review test

A screen succeeds when a first-time user can identify the work surface, context,
inspector, selected object, and likely next action within seconds. It should
remain understandable when color is removed and grow calmer — not more cluttered —
as its logic becomes familiar.
