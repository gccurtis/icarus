# .envrc — breakdown

Companion to [.envrc](.envrc). Read by [direnv](https://direnv.net/) to
auto-load the environment when you `cd` into the project.

## direnv directive

### Load the flake devShell automatically

```bash
use flake
```

`use flake` tells direnv (via its nix integration) to enter this repo's
`devShells.default` whenever you're inside the directory, and to drop back out
when you leave. Combined with `direnv allow`, it means Node, pnpm, and the Nix
tooling are on `PATH` automatically — no manual `nix develop` needed. It reads
`flake.nix` in the same directory by default.
