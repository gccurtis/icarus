# library

Collections and launchers: the every-X lists, the recents, and everything a
launcher can make, start from, or bring in.

**Two kinds of answer live here.** A collection answers with what the project
already holds. A launcher answers with the draft state a tab is holding for
something that does not exist yet — still a capability rather than a prop,
because those defaults are what the editor will show once Create is pressed.

Serves `docs/screen-panel-views/{context,inspector}/library/`.

**It answers nothing yet.** The views that call it name what it owes them.
