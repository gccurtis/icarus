# resource

A resource being edited — a document, a slide deck or a spreadsheet — and every
part of one you can select.

The largest capability in the tree: fifty-eight panels across three editors, so
the procedures are grouped by editor rather than run together alphabetically.

Serves `docs/screen-panel-views/{context,inspector}/resource/`.

**It answers nothing yet.** The views that call it name what it owes them.
