# scope

Contexts: what a question is allowed to look at.

**A Context is a rule, not a list** — Include minus Take out, one level deep,
resolved at the moment it is read. Every procedure is scoped by a Context id and
answers with counts as of now rather than a stored membership, so a document
created tomorrow that fits the rule is in it without anyone editing anything.

Serves `docs/screen-panel-views/{context,inspector}/scope/`.

**It answers nothing yet.** The views that call it name what it owes them.
