# project

The project as a whole: what is in it, who is in it, what has happened, and what
cannot proceed.

**Every list is a project-scoped query, never a stored array on the project.**
That is the rule Project Overview keeps, and it is why this is a set of procedures
rather than one blob.

Serves `docs/screen-panel-views/{context,inspector}/project/`.

**It answers nothing yet.** The views that call it name what it owes them.
