# Semantic Sets

A set assigns five identity anchors to chromatic hues. Each file is a complete
35-alias table: five anchors across the seven chromatic jobs. Sets never assign
fixed meanings; success, danger, attention, and inactive remain fixed in the
color-token layer.

Primary, secondary, and tertiary must be distinct. Accent hues cannot use the
fixed meaning hues `green`, `red`, `amber`, or `grey`.
